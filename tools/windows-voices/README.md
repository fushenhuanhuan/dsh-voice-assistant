# Windows 系统语音补登记（可选）

**这里的东西不是插件的一部分**，插件运行完全不需要它们。只有把「朗读引擎」切到 **系统语音（离线）**、又想用康康 / 瑶瑶这两个中文音色时才用得上。

## 背景

Windows 10 桌面能直接给网页（SAPI5）用的中文语音通常只有一个「慧慧」。系统里其实还带着 **康康（男声）** 和 **瑶瑶（女声）**，但只注册在 OneCore 下，网页语音列表里看不到。这里的 `.reg` 把这两个补登记到 SAPI5。

## 用法

1. 双击 `enable-kangkang-yaoyao.reg`，确认 UAC 与合并提示；
2. 完全退出并重新打开 DSH；
3. 设置 → 通用 → 语音助手 → 配置 → 「朗读引擎」选 **系统语音** → 「朗读音色」里选康康或瑶瑶。

想还原就双击 `revert-kangkang-yaoyao.reg`，然后同样重启 DSH。

## 注意

- 这两个文件只写 `HKEY_CURRENT_USER`（`HKCU`）下的 SAPI5 Voices 键，不碰系统级 `HKLM`，不需要管理员权限以外的操作。
- 合并前建议先导出自己的对应注册表项备份；`revert` 只删除本目录 `enable` 添加的那几个子键。
- 三个系统音色都是同一代老引擎，只在性别上不同；想听更自然的声音请用 MiMo 或 Edge 引擎。
